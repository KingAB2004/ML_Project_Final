    The whole program

    Four stages, each a set of scripts that read files and write files. The corpus trains the supporter; the supporter runs inside the four-agent pipeline with the gate and the memory; a separate judge scores every conversation afterwards.

    One supporter turn, in detail

    The four agents are views of one model; only the Generator is fine-tuned. Each agent narrows what the next may do: the Analyzer's confidence and the memory set the ladder's cap, the Strategist plans inside it, and the Critic and the gate check the draft before the seeker sees anything.

    Need-state memory: architecture

    The memory (src/memory.py) is one object per person. Writes come only from the Analyzer's grounded claims, after the reply is chosen. Reads happen before the next turn: a short brief for the prompts, plus the denied and stale needs the Critic checks against. Every change is a row in an append-only log.

    Need-state memory: the belief graph

    Memory holds beliefs about needs, not facts. Each node is a need with a status, a confidence and the seeker's own words as evidence. Edges run from a need to the shallower need it explains; siblings are rival explanations. The example below shows every status at once.

    How a belief changes

    Only a claim with a quote enters. A denial is final: the guess is blocked and everything below it goes dormant.

    Across sessions: decay

    At the start of each session every belief except a denial fades by 0.5gap / half-life. A need that keeps coming back lasts longer. The dot marks day 34, when an unsupported hypothesis leaves the brief.

    What the agents see: the brief

    One supporter turn

    Analyzer

    Reads the raw turns plus the memory brief. Writes the surface feeling and candidate needs. Every claim carries quoted evidence spans and a confidence.

    Depth ladder

    Below 0.45 confidence the turn is capped at L1. L3, naming the terminal need, also needs that need confirmed in memory.

    Strategist

    Picks a plan and a rung within the cap, with a justification chain and the memory node it targets.

    Generator

    Writes the reply from the plan. In the full system this is the QLoRA fine-tuned Qwen2.5-7B.

    Critic + gate

    Predicts IP on 7 items and checks grounding. A draft is released only if its score is at most λ̂; otherwise it is revised up to twice, then replaced by a reflective fallback.
